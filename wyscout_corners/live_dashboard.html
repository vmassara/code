Wyscout corner-kick analysis

Runs entirely in your browser: credentials go straight from this page to apirest.wyscout.com over HTTPS, and are never sent anywhere else or stored.

Known issue: this doesn't currently work. Wyscout's API doesn't send the Access-Control-Allow-Origin header a browser requires to call it directly, so every request fails with a CORS error before it even reaches your credentials. This isn't fixable from this page — use the Python version instead (cli.py in the same wyscout_corners folder), which talks to the API directly and isn't subject to this browser-only restriction. See that folder's README for setup.
